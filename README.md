## 🚀 Featured Projects

### 🤖 AI-Powered Customer Support Automation System

An agentic AI customer-support automation system built using LangGraph and LangChain. The system classifies customer queries, dynamically routes them to specialized support agents, retrieves relevant information from company documents using RAG, maintains conversation history using SQLite, and uses Human-in-the-Loop approval for high-risk requests.

**Key Features**
- Intent classification and conditional routing
- Specialized Sales, Technical, Billing, and Account agents
- RAG-based document retrieval
- FAISS vector search
- HuggingFace embeddings
- SQLite-based conversation memory
- Human-in-the-Loop approval
- Supervisor Agent for workflow coordination
- Professional response generation

**Tech Stack:**  
`Python` `LangChain` `LangGraph` `RAG` `FAISS` `HuggingFace` `SQLite` `Sentence Transformers`
